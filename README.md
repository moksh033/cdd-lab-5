## Experiment 5 Overview
This repository demonstrates team collaboration workflows using GitHub Flow:
- Multiple contributors working in parallel on isolated feature branches (`feature-ui` and `feature-backend`)
- Simulating and resolving simultaneous merge conflicts on shared source files (`app.py`)
- Enforcing branch protection rules on `main` to mandate pull request reviews before integration
- Maintaining a clean, auditable Git history with explicit merge commits
